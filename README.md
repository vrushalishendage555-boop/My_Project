# Gavran Khajina

## Traditional Maharashtrian Recipe Website

Gavran Khajina is a web-based application that showcases authentic Maharashtrian traditional recipes. The platform allows users to explore various regional dishes, learn cooking methods, and experience the rich food culture of Maharashtra.

## Features

* User Registration and Login
* Browse Traditional Maharashtrian Recipes
* Recipe Categories
* Detailed Recipe Information
* User-Friendly Interface
* Responsive Design
* Admin Panel for Recipe Management
* Database Integration

## Technologies Used

### Frontend

* HTML
* CSS
* JavaScript
* Bootstrap
* JSP

### Backend

* Java
* Spring Boot

### Database

* MySQL

## Project Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/vrushalishendage555-boop/My_Project.git
   ```

2. Import the project into Eclipse/STS.

3. Configure MySQL database settings.

4. Run the Spring Boot application.

5. Open the application in your browser.
